隱私權政策

本政策適用於由 danny541690 管理的 JARVIS-C1-DATA 個人研究工具。

存取及用途

工具透過管理者的 Google OAuth 授權存取 Google Drive。處理內容包括賈維斯資料夾及檔案的名稱、識別碼、必要中繼資料、研究資料檔、檢查報告與排程控制檔。用途為保存、讀取、檢查與補正研究資料，以及延續排程進度。

目前使用完整 Drive scope。此授權在技術上允許廣泛的檔案存取；工具預定用途限於賈維斯資料處理，使用者應在授權前理解其權限範圍。

保存與處理環境

研究資料與控制檔主要存放在管理者的 Google Drive。GitHub Actions 執行程式時可能暫存及處理相關內容。OAuth 用戶端密鑰與 refresh token 透過 GitHub Actions Secrets 提供給工作流程，不應寫入公開網站或儲存庫。執行紀錄可能包含技術錯誤、檔案識別碼及處理進度；應避免輸出檔案私密內容及憑證。

分享與限制使用

本工具不以出售 Google 使用者資料或廣告投放為目的，也不將其用於訓練通用人工智慧模型。資料依上述用途由 Google Drive 與 GitHub Actions 等必要服務處理；這些服務亦受各自政策規範。

JARVIS-C1-DATA 對 Google API 資料的使用及向其他應用程式移轉，將遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、刪除及撤銷

資料原則上保留至管理者刪除。管理者可刪除 Drive 內資料、GitHub 暫存產物及執行紀錄，並移除 Actions Secrets。可在 Google 帳戶第三方連線撤銷應用程式授權；撤銷會阻止後續存取，但不會自動刪除先前已保存的資料或備份。

公開網站與聯絡

本說明網站不設定分析追蹤或登入表單；GitHub Pages 可能依其政策處理訪客連線紀錄。政策問題或刪除請求可聯絡本頁下方電子郵件。資料處理方式變動時將更新此政策。
